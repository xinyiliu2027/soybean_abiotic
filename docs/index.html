03 / DATA & METHODS

From RStudio to an interactive atlas

01

Export from Seurat

Run the exporter in RStudio on the server containing your merged Seurat RDS. It exports existing UMAP coordinates, treatments, cell annotations, and all-gene cell-type summaries in small files. Sparse UMAP vectors are included when they fit the configured export budget.

Download the R exporter ↗
02

Import your atlas

In RStudio Files, select atlas.json, then More → Export → Download. On this website choose Import atlas JSON. For all-gene summaries, download the entire export folder and choose Import expression folder. Local imports stay in this browser session.

No dataset provenance available yet.

03

Compare stress responses

Required CSV columns: gene, celltype, treatment, logFC, padj. Treatment must be Heat, Cold, or PEG. Use log2 fold changes and document the reference. The bundled filtered table uses REF; absent rows cannot be interpreted as unchanged.

Download the DE CSV header ↗
Reference & interpretation

The exploration concept was informed by the Zhai lab Arabidopsis hormone single-nucleus study. This independent site is for soybean stress data. Shared-response candidates require genetic and phenotypic validation before breeding relevance can be established.

Nature Communications · Reference ↗

Run the Shiny app on the server containing your Seurat RDS for arbitrary RNA gene UMAP across CK, Heat, Cold, and PEG, without exporting JSON first. The app also exports 600 dpi figures and atlas.json. GitHub Pages does not run R.
